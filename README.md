# بورتفوليو شخصي

## التقنيات

HTML وCSS.

## فكرة المشروع

عرض المهارات والمشاريع باستخدام تنسيق portfolio.css وحركات CSS.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `index.html`
- `portfolio.css`

## حدود المشروع
