Campus Network

I built a campus network connecting five buildings and ten floor networks. The project combines a mesh between the main routers with static routing, central services and wireless access.

  • IPv4 subnetting with /24 LANs and /30 router links.
  • Static routes, default routes and DHCP relay.
  • DHCP, DNS, web, email and LMS services.
  • Wireless access, a project report and a video walkthrough.
